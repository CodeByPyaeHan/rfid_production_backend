// Flow 
Frontend (React)
    ↓ upload excel
Backend (Express)
    ↓ multer (receive file)
    ↓ xlsx (parse excel → json)
    ↓ mapping (json → marc_json)
    ↓ mongoose (save to MongoDB)

// Installation 
# npm install express multer xlsx mongoose dotenv
